Coin Toss Flask App

This is the live GitHub Pages site for the Indian 1 rupee coin toss Flask project. The app itself runs locally in Python, while this page serves as the project website with demo information, features, and source links.

What this app does

The project includes a Flask app with an interactive coin toss UI, animated coin flip, heads/tails tracking, a running score, and a reset button. The app now also uses a static GitHub Pages site for project documentation and links.

How to run it locally

Clone the repository and run the Flask server:

git clone https://github.com/sharkboi007/coin-toss-flask.git
cd coin-toss-flask
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
